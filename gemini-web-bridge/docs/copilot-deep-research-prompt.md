# پرامپت Deep Research برای GitHub Copilot

> این فایل یک پرامپت آماده است. آن را کپی کنید و در **GitHub Copilot Chat** (حالت Agent) یا در یک Issue در مخزن خودتان با `@copilot` بفرستید تا تحقیق عمیق و ساختاریافته انجام دهد.
>
> نکته: Copilot به وب دسترسی دارد ولی همیشه نتایج را راستی‌آزمایی کنید — پرامپت زیر طوری نوشته شده که منابع و تاریخ‌ها را ملزم به گزارش کند.

---

## پرامپت (کپی کنید)

```text
وظیفه: تحقیق عمیق (Deep Research) درباره تبدیل اشتراک وب gemini.google.com به API استاندارد — بررسی کامل اکوسیستم تا امروز.

زمینه: من یک پل محلی دارم: gemini-web2api-go (موتور وب با اثرانگشت کروم، Cookie Pool) + CLIProxyAPI (پل /v1/messages) + 9router به‌عنوان روتر مرکزی. می‌خواهم بدانم دنیا چه کرده، چه چیزهایی از بقیه جلوتر است و چه ایده‌هایی را جا افتاده.

سوالات تحقیق — همه را با منبع (لینک + تاریخ) جواب بده:

۱. نقشه رقبا (فوریه ۲۰۲۵ تا امروز):
   - ریپوهای گیت‌هاب با موضوع «gemini web to api»، «gemini2api»، «gemini cookie proxy»، «bard api cookie» را با gh search و جستجوی وب پیدا کن.
   - برای هر کدام: ستاره، آخرین push، زبان، روش انتقال (httpx / curl_cffi / rnet / Go uTLS / مرورگر)، پشتیبانی چند-اکانت، پشتیبانی استریم و Tool Calling.
   - جدول مقایسه بساز و مشخص کن کدام‌ها «processSession» جدید گوگل (geminiweb-pa.clients6.google.com) را پیاده کرده‌اند.

۲. مدیریت چند-اکانته کوکی:
   - الگوهای شناخته‌شده برای چرخش امن کوکی‌های Google (RotateCookies، __Secure-1PSIDTS، DBSC) را بیاب.
   - کدام پروژه‌ها «قفل تک‌نویسنده» (single-writer) و «اتصال اکانت به IP» (sticky IP) دارند؟ چه کدی؟ لینک فایل.

۳. مسیر Antigravity OAuth در برابر مسیر وب‌کوکی:
   - وضعیت موج‌های مسدودسازی گوگل (مارس ۲۰۲۶، نوامبر ۲۰۲۶) را از Issues پروژه‌های 9router، CLIProxyAPI، OmniRoute و ساب‌ردیت‌ها جمع کن.
   - مشخص کن کدام مسیر امروز (تاریخ امروز) ریسک کمتری دارد و چرا.

۴. سهمیه‌ها:
   - سهمیه ۵ ساعته مدل‌های Gemini 4 (Hydrogen / Neon / Carbon) روی پلن Pro چقدر است؟ اعداد گزارش‌شده واقعی کاربران را جمع کن (Reddit، Issues، YouTube).
   - کسی الگوریتمی برای پیش‌بینی سهمیه باقی‌مانده (پروب سبک بدون مصرف چت) منتشر کرده؟

۵. یوتیوب:
   - ویدیوهای آموزشی «gemini web api proxy»، «gemini web2api»، «9router tutorial»، «claude code free gemini» را پیدا کن؛ برای هر ویدیو: عنوان، کانال، تاریخ، مدت، خلاصه یک‌خطی و اینکه چه ابزاری معرفی می‌کند.

۶. جمع‌بندی:
   - ۱۰ نتیجه‌گیری کلیدی که روی پروژه من اثر دارد.
   - ۵ ایده که هیچ‌کس هنوز پیاده نکرده (فرصت).
   - ۳ هشدار که در منابع تکرار شده.

قواعد خروجی:
- هر ادعا با لینک مستقیم (ریپو/ایشو/ویدیو) و تاریخ؛ اگر منبع قدیمی‌تر از ۳ ماه است، صراحتاً بنویس «قابل استناد با احتیاط».
- اعداد حدسی نزن؛ اگر چیزی پیدا نشد بنویس «یافت نشد» نه حدس.
- جدول‌های Markdown، فارسی؛ اسم ابزارها انگلیسی بماند.
- در انتها یک فایل به اسم RESEARCH.md در ریشه مخزن بساز و همه را همان‌جا بنویس.
```

## چطور استفاده کنیم

### راه ۱: در VS Code با Copilot Chat
1. مخزن [gemini-web-bridge](https://github.com/armanpoor/gemini-web-bridge) را باز کنید.
2. Copilot Chat را روی حالت **Agent** بگذارید.
3. کل بلوک بالا را کپی و پیست کنید و Enter.

### راه ۲: به‌صورت Issue در گیت‌هاب (بدون VS Code)
1. در مخزن، یک Issue جدید باز کنید با عنوان `Deep Research: gemini-web2api ecosystem`.
2. متن پرامپت را در بدنه Issue بگذارید و اولش `@copilot` اضافه کنید.
3. Copilot در همان Issue شروع به تحقیق و نوشتن می‌کند.

### راه ۳: Claude Code (این ابزار)
همین پرامپت را در یک سشن Claude Code تازه بدهید — چون Claude Code به `gh` و وب هم دسترسی دارد، همان خروجی را با کیفیت معمولاً بالاتر می‌دهد.

## نکته‌های داخلی پرامپت (چرا این‌طوری نوشته شده)

- **«با منبع و تاریخ»** — جلوی توهم (hallucination) را می‌گیرد؛ مدل مجبور است لینک بدهد و راحت‌تر راستی‌آزمایی می‌شود.
- **«جدول بساز»** — خروجی مقایسه‌ای بهتر از متن روایی است.
- **«یافت نشد» به‌جای حدس** — مهم‌ترین قاعده تحقیق؛ مدل‌ها تمایل دارند جای خالی را پر کنند.
- **«فایل RESEARCH.md بساز»** — خروجی در مخزن می‌ماند و قابل ادامه‌دادن است.
- بخش ۶ عمداً «نتیجه‌گیری برای پروژه من» است نه خلاصه عمومی — تا تحقیق به تصمیم ختم شود نه گزارش.
